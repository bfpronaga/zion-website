## Next.js Image Optimization

All images in the `/public` folder are automatically optimized by Next.js when using the `<Image>` component:

### Features
- ✅ Automatic WebP/AVIF conversion (when supported)
- ✅ Responsive image sizing
- ✅ Lazy loading by default
- ✅ Blur placeholder generation
- ✅ No layout shift (with proper width/height)

### Usage Example

```tsx
import Image from 'next/image';

// For static images
<Image
  src="/images/logo.png"
  alt="シオンとの架け橋"
  width={340}
  height={55}
  priority // For above-the-fold images
/>

// For hero images with fill
<Image
  src="/images/hero-jerusalem.jpg"
  alt="エルサレム旧市街"
  fill
  className="hero-image"
  priority
/>
```

## Future Additions

When adding more content:
1. Place new images in appropriate folders under `/public/images/`
2. Use descriptive filenames (lowercase, hyphens instead of spaces)
3. Keep original aspect ratios for content images
4. Provide proper alt text for accessibility
5. Use Next.js Image component for automatic optimization
