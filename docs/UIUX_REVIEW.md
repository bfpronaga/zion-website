# UI/UX レビュー - Zion Website Homepage MVP

**日付:** 2026年11月14日  
**対象:** index-modern.html & index-original.html  
**表面種別:** ホームページ / ランディング（受賞・ポートフォリオ級を目指す）

---

## 一言判定

**index-modern.html:** プロモ可 / 受賞にはあと一歩（75/100点）  
**index-original.html:** 実務可 / プロモ良好（70/100点）

両バージョンとも、典型的なAIデフォルトから十分に離れており、ブランド性を保持している。
しかし、受賞級サイトと比較すると、意図的モーション・写真の使い方・タイポグラフィの編集性でやや不足。

---

## Anti-AI チェック ✅

### 避けるべき要素（チェック済み）

| 避ける要素 | 状態 | コメント |
|-----------|------|----------|
| 紫〜インディゴのグラデ、グロー | ✅ 回避済 | ブルー系のブランドカラーを使用 |
| Inter / Roboto / Arial 既定 | ✅ 回避済 | Noto Sans JP & Playfair Display を使用 |
| 丸ピルの群、バッジ／チップの浮遊 | ⚠️ 一部あり | video-badge に若干のピル形状あり。機能的なので許容範囲 |
| 絵文字装飾の過剰使用 | ⚠️ 使用あり | アイコンとして絵文字使用。UI アイコンに差し替えを検討 |
| クリーム＋テラコッタ + セリフの LP 型 | ✅ 回避済 | 独自のブルー・コーラル・ゴールドパレット |
| カードだらけのダッシュボード風 | ⚠️ 中程度 | カード使用あるも、適切な間隔と階層あり |
| 抽象グラデだけのビジュアル | ⚠️ 改善余地 | 実写真・イスラエル関連のビジュアルが不足 |

**総評:** AIっぽさの大半は回避できているが、実写真・固有ビジュアルの不足が「汎用テンプレート感」を残している。

## ホームページ必須チェック（5項目）

### 1. Brand Test ⭐⭐⭐⚪⚪ (3/5)

**結果:** ナビを消すとブランド性がやや弱まる

- ✅ ロゴマーク（🌉）とタイトル「シオンとの架け橋」は明確
- ✅ ブルー・コーラルの配色はブランド一貫性あり
- ⚠️ イスラエル特有のビジュアル（エルサレム・ダビデの星・オリーブなど）が不在
- ❌ ヘブライ語フォントや右から左への要素など、イスラエルを象徴する視覚言語が欠落

**改善:** イスラエルの風景写真をヒーローセクションに配置、またはモチーフをあしらう

### 2. First Viewport (Impact) ⭐⭐⭐⭐⚪ (4/5)

**結果:** 0.5秒で理解可能。ただしインパクトは中程度

**index-modern.html:**
- ✅ ヒーローコピー「イスラエルと日本をつなぐ架け橋として」は明確
- ✅ CTA「無料メールマガジンに登録」は視認性高い
- ⚠️ ビジュアルがグラデーションのみ。実写真がないため印象に残りにくい

**index-original.html:**
- ✅ アナウンスメント優先で情報密度高い
- ⚠️ ヒーロー感が弱い。第一印象が「お知らせ掲示板」に近い

**改善:** ヒーローに高品質なイスラエルの写真を配置（エルサレム旧市街、嘆きの壁など）

### 3. Atmosphere (おしゃれさ / 空気感) ⭐⭐⭐⚪⚪ (3/5)

**結果:** クリーンで整っているが、「編集的な洗練」が不足

- ✅ 余白の使い方は適切
- ✅ カラーパレットは落ち着いている
- ⚠️ タイポグラフィのコントラストがやや弱い（見出しと本文のサイズ差が控えめ）
- ❌ 写真がないため、「雑誌的・編集的な美しさ」に欠ける
- ❌ 非対称レイアウトがない（すべて中央揃えまたはグリッド）

**改善例:**
- ヒーローを左右非対称に（テキスト左、イメージ右など）
- 見出しフォントサイズをさらに大きく（3.5rem〜4rem）
- イスラエル関連の高品質写真を3〜5枚配置

### 4. Desire (触りたくなるか) ⭐⭐⭐⭐⚪ (4/5)

**結果:** CTAは明確で誘導はできているが、感情喚起がやや弱い

- ✅ CTA ボタンのコントラストとホバー効果は良好
- ✅ YouTube動画の埋め込みで興味喚起できている
- ⚠️ ストーリー性が弱い（なぜイスラエルを知るべきか、の感情訴求）
- ⚠️ ユーザーの声、実績、社会的証明が不在

**改善:** 
- 「1000人以上が購読中」などの数字を追加
- 短い推薦文やストーリーを添える

### 5. Motion (意図的なモーション 2〜3) ⭐⭐⚪⚪⚪ (2/5)

**結果:** ホバー効果のみ。入場アニメーションや scroll-driven motion が不在

**現状:**
- ✅ カードホバーで `translateY(-8px)` の動き
- ✅ ボタンホバーで影の変化
- ❌ ページロード時の入場アニメーションなし
- ❌ スクロールに応じた視差効果やフェードインなし
- ❌ ブランドを印象づける「決め」のモーションがない

**改善 (P1):**
1. ヒーローセクションの要素にフェードイン・スライドイン（stagger）
2. スクロール時に各セクションが順次フェードイン（Intersection Observer）
3. `prefers-reduced-motion: reduce` で無効化

## 改善提案（優先度付き・最大7件）

### P0 (Critical - すぐ対応すべき)

#### 1. **実写真の追加** (Size: M)
**何が弱い:** グラデーションのみで、イスラエルの「場所性」「手触り」が伝わらない  
**なぜ:** 受賞サイトは必ず製品・場所・人物の実写を持つ。抽象ビジュアルだけでは感情喚起が弱い  
**望ましい結果:** 
- ヒーローに高解像度のエルサレム旧市街 or 嘆きの壁の写真
- セクション背景に淡く風景を敷く（opacity: 0.1〜0.2）
- イスラエルの市場、風景、人々の写真を3枚追加

#### 2. **絵文字アイコンをSVGアイコンに差し替え** (Size: S)
**何が弱い:** 絵文字（🌉📰🎬📖など）はAI生成サイトの典型  
**なぜ:** プロフェッショナルなサイトはカスタムアイコンを使う  
**望ましい結果:** 
- Heroicons / Lucide / カスタムSVGに差し替え
- ブランドカラーでスタイリング
- size: 24px〜32px で統一

### P1 (High - 受賞級に必要)

#### 3. **入場アニメーションの実装** (Size: M)
**何が弱い:** ページロード時に静的で、インパクトが弱い  
**なぜ:** 受賞サイトは第一印象の0.5秒で「動き」を見せる  
**望ましい結果:**
```css
/* ヒーロー要素に順次フェードイン */
.hero h2 { animation: fadeInUp 0.8s ease-out 0.1s both; }
.hero p { animation: fadeInUp 0.8s ease-out 0.3s both; }
.cta-button { animation: fadeInUp 0.8s ease-out 0.5s both; }

@keyframes fadeInUp {
  from { opacity: 0; transform: translateY(30px); }
  to { opacity: 1; transform: translateY(0); }
}

@media (prefers-reduced-motion: reduce) {
  * { animation: none !important; }
}
```

#### 4. **タイポグラフィの強化** (Size: S)
**何が弱い:** 見出しと本文のサイズ差が控えめで、ヒエラルキーが弱い  
**なぜ:** 編集的な美しさは大胆なタイポから生まれる  
**望ましい結果:**
- ヒーローh2: 2.8rem → 3.8rem（デスクトップ）
- セクションタイトル: 2.2rem → 2.8rem
- font-weight: 700 → 800 (一部)
- letter-spacing を微調整（-0.02em）

#### 5. **非対称レイアウトの導入** (Size: L)
**何が弱い:** 全てが中央揃え or 均等グリッド。編集性に欠ける  
**なぜ:** 受賞サイトは意図的な非対称でブランドの「声」を出す  
**望ましい結果:**
- ヒーローを 60:40 の左右分割に（テキスト左、ビジュアル右）
- イベントバナーの日付を左に配置し、右のテキストと非対称に
- 一部のセクションを full-bleed（左右いっぱい）に

### P2 (Medium - 磨き上げ)

#### 6. **スクロールフェードインの追加** (Size: M)
**何が弱い:** スクロール時の変化がなく、長いページが単調  
**なぜ:** 視線誘導と階層作りに有効  
**望ましい結果:**
```javascript
// Intersection Observer で各セクションをフェードイン
const observerOptions = { threshold: 0.1, rootMargin: '0px 0px -100px 0px' };
const observer = new IntersectionObserver((entries) => {
  entries.forEach(entry => {
    if (entry.isIntersecting) {
      entry.target.classList.add('fade-in-visible');
    }
  });
}, observerOptions);

document.querySelectorAll('section').forEach(el => observer.observe(el));
```

#### 7. **ソーシャルプルーフの追加** (Size: S)
**何が弱い:** 信頼性の証明がない  
**なぜ:** 「1000人購読中」などの数字は行動を促す  
**望ましい結果:**
- ニュースレターセクションに「2,000人以上が購読中」バッジ
- 「20年以上の活動実績」などの数字
- 小さくでも OK（過剰な装飾は不要）

## 次に engineer が触るべき1件（推奨）

### **🎯 最優先: 実写真の追加 (P0-1)**

**理由:**
1. 最も大きなインパクト改善（視覚的空白を埋める）
2. 実装が明確（画像配置のみ）
3. 他の改善（アニメーション、タイポ）の土台になる

**具体的タスク:**
1. イスラエルの高解像度写真を3枚取得（Unsplash or クライアント提供）
   - エルサレム旧市街 (hero用)
   - 市場・風景 (section背景用)
   - 文化的シンボル (card用)
2. ヒーローセクションを左右分割レイアウトに変更
   - テキスト: 左 50%
   - 写真: 右 50%, object-fit: cover, border-radius: 20px
3. モバイルでは縦積みに（写真が上）

**期待効果:**
- ブランドテストが 3/5 → 4.5/5 に向上
- First Viewport インパクトが 4/5 → 4.5/5 に向上
- 「汎用テンプレート感」が大幅に減少

## 細かい技術的指摘

### CSS
- ✅ CSS 変数でテーマ管理（良好）
- ✅ トランジション・ホバー効果適切

- ✅ セマンティック HTML 使用（section, h1-h3 適切）

### パフォーマンス
- ✅ YouTube iframe は遅延読み込み推奨（`loading="lazy"`）
- ✅ Google Fonts は `preconnect` 済み
- ⚠️ 実写真追加時は WebP 形式 + responsive images (`srcset`)

## 参考: 受賞級サイトとの比較

### 強い点 ✅
- クリーンなコード構造
- ブランドカラーの一貫性
- モバイル対応
- AI デフォルトから十分に離れている

### 弱い点（受賞級との差）
- **ビジュアルの不在:** 写真がないため、感情喚起が弱い
- **モーションの欠如:** 静的すぎて、第一印象が平坦
- **タイポのインパクト不足:** 見出しがもう一段大きくあるべき
- **非対称性の欠如:** 全てが整然としすぎて、編集的な美しさに欠ける

**ベンチマーク例（同ジャンル）:**
- Awwwards SOTD の非営利団体サイト
- 文化系団体のランディング（例: museum sites, cultural bridges）
